A few useful details

Glad you asked.

Does my computer need to stay on?

Yes. Your coding agent, bridge, and local relay run on your host. Keep it awake and reachable while you’re connected. The optional desktop host can supervise the local processes for you.

Can I use it away from home?

Yes, with a reachable relay. Use a VPN such as Tailscale, or self-host a relay for access outside your local network. Read the connection guide ↗

Which agents and devices work?

Codex, Claude Code, opencode, and Cursor are supported. Codex requires macOS and Codex.app; the other providers work on macOS and Linux. Connect with the iOS app, Android app, or browser client. Android is currently alpha, and features vary between clients.

Is agnt a hosted service?

No. You run the bridge and relay yourself. agnt doesn’t provide hosted agents or model subscriptions; you use your own agent installation and provider account.

Is it open source?

agnt is source-available under PolyForm Shield 1.0.0, which includes a non-compete restriction. You can read the code and self-host it. Read the license ↗
